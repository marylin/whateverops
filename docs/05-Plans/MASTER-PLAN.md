# WhateverOPS — Master Plan

Unified ops dashboard for solo developer-founders.
15 integrations. Flat pricing. No agents. Open source.

---

## 6-Phase Roadmap

| Phase | Name | Timeline | Gate to unlock |
|-------|------|----------|---------------|
| 0 | Foundation | Days 1–2 | CI green + monorepo running |
| 1 | Personal Dashboard | Days 3–7 | Gate 0: 7 days daily use |
| 2 | Polish & OSS Prep | Weeks 2–3 | Gate 1: 10+ unprompted requests |
| 3 | OSS Launch | Weeks 4–6 | Gate 2: 20 confirmed self-hosters |
| 4 | Hosted Beta | Months 2–3 | Gate 3: 60% WAU + Gate 4: Sean Ellis |
| 5 | Paid Launch | Months 3–4 | Gate 4 confirmed |
| 6 | Growth | Months 4–6+ | $500+ MRR |

## PMF Gates

| Gate | Condition | Unlocks |
|------|-----------|---------|
| 0 | 7 consecutive days personal daily use | Phase 2 |
| 1 | 10+ unprompted DMs / GH issues asking to try | Phase 3 |
| 2 | 20+ confirmed self-hosted instances | Phase 4 |
| 3 | 60%+ WAU for 2 consecutive weeks | Phase 5 |
| 4 | 40%+ "very disappointed" Sean Ellis survey | Phase 6 |
